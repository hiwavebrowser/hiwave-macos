## What this does and does not measure

- Order: the "sites" column counts sites of the 67 loaded from the top-100 list whose main frame authors the property in a stylesheet, `<style>` or style attribute. Authored is not applied: whether the rule matched anything is not measured. A shorthand and its longhands are separate names, and sites behind a bot wall, ebay and shopify are not in the count. Ties sort by declarations authored in the 26-case corpus.
- One fixture per value in one context. A class says what happened there, not that every value form or context works.
- An `unexercised` value changed nothing in Chrome, so it cannot pass effect; `not-visual` properties paint nothing in a static frame and stop at computed.
- An arm that applies a property and is then ignored still counts as parse.
- `control N off`: the row's own control, its `base` declarations included, is N probes off Chrome, so the red belongs to that control first. That may be the row's `base` and not its context; the context's own number is in the list below.

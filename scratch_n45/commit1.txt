`match_pseudo_class` ended in `_ => true`, so every pseudo-class the arm
list did not name matched EVERY element: `:is()`/`:where()` (every modern
reset's `:where(ul, ol) { padding: 0 }` zeroed padding everywhere), the

member. And `tokenize_selector` split at whitespace inside parentheses,
so `:is(.a, .b)` was two tokens — `:is()` could never have worked.

A web browser is an application for accessing websites. When a user requests a web page from a particular website, the browser retrieves its files from a web server and then displays the page on the screen. Browsers can also display content stored on the local file system.

Once a page has been retrieved, the rendering engine of the browser displays it on the screen. Most browsers also support a wide variety of other formats, such as images, video and audio, and plugins extend them further. Pages usually contain hyperlinks to other pages and resources, and each link contains a URL; when it is clicked, the browser navigates to the new resource, and the process of bringing content to the user begins again.

A web browser is an application for accessing websites. When a user requests a web page from a particular website, the browser retrieves its files from a web server and then displays the page on the user's screen. Browsers run on a range of devices, including desktops, laptops, tablets, and smartphones.

By 2020, an estimated 4.9 billion people had used a browser. The most used browser is Google Chrome, with a 64% global market share on all devices, followed by Safari with 19%. Other notable browsers include Firefox and Microsoft Edge. A web browser is not the same thing as a search engine, though the two are often confused. A search engine is a website that provides links to other websites, while a browser displays them.

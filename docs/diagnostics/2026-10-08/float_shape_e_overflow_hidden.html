A web browser is an application for accessing websites. When a user requests a web page from a particular website, the browser retrieves its files from a web server and then displays the page on the screen. Browsers can also display content stored on the local file system. The purpose of a browser is to fetch content and display it on the device of the user. This process begins when the user types a URL into the address bar. Virtually all URLs on the Web start with either http or https, which means they are retrieved with the Hypertext Transfer Protocol.

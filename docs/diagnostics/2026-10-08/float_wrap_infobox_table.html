A web browser is an application for accessing websites. When a user requests a web page from a particular website, the browser retrieves its files from a web server and then displays the page on the user's screen. Browsers run on a range of devices, including desktops, laptops, tablets, and smartphones.

The first web browser, called WorldWideWeb, was created in 1990. It was later renamed Nexus to avoid confusion with the World Wide Web itself. Many browsers followed, and the browser wars of the late 1990s and the 2000s shaped the web as it is used today. Modern browsers share a set of standards, so a page written once looks the same in all of them.

Default-rule handling was also fixed (SH2, [#1132](https://github.com/hiwavebrowser/hiwave-macos/pull/1132)). - **Hardening:** autofill hardening ([#1034](https://github.com/hiwavebrowser/hiwave-macos/pull/1034)); engine-only `isTrusted` and host-side entry points ([#1123](https://github.com/hiwavebrowser/hiwave-macos/pull/1123)); host object hardening ([#1155](https://github.com/hiwavebrowser/hiwave-macos/pull/1155)); install-time built-ins on bookkeeping paths ([#1161](https://github.com/hiwavebrowser/hiwave-macos/pull/1161)); the iframe `sandbox` attribute for nested contexts, behind the frames flag ([#1201](https://github.com/hiwavebrowser/hiwave-macos/pull/1201)).

### Chrome look-alike UI (16 PRs)
- **Tabs and keyboard:** Cmd+W always closes the active tab (M1, [#1004](https://github.com/hiwavebrowser/hiwave-macos/pull/1004)). Tabs keep one explicit strip order (M1c, [#1010](https://github.com/hiwavebrowser/hiwave-macos/pull/1010)). Tab-switch shortcuts work from a focused page (M1d, [#1012](https://github.com/hiwavebrowser/hiwave-macos/pull/1012)). Page-first Cmd chords have a 100 ms limit (M1e, [#1015](https://github.com/hiwavebrowser/hiwave-macos/pull/1015)), and timed-out chords are handled once (M1g, [#1023](https://github.com/hiwavebrowser/hiwave-macos/pull/1023)). Escape in the address bar reverts or stops (M1f, [#1022](https://github.com/hiwavebrowser/hiwave-macos/pull/1022)).
- **Chrome board rows:** form-control paint (CB1a/CB1b, [#1025](https://github.com/hiwavebrowser/hiwave-macos/pull/1025), [#1027](https://github.com/hiwavebrowser/hiwave-macos/pull/1027)); button height, width and wrapping (CB3, CB3c, CB3d: [#1037](https://github.com/hiwavebrowser/hiwave-macos/pull/1037), [#1061](https://github.com/hiwavebrowser/hiwave-macos/pull/1061), [#1093](https://github.com/hiwavebrowser/hiwave-macos/pull/1093)); the collapsed right sidebar (CB6, CB6c: [#1065](https://github.com/hiwavebrowser/hiwave-macos/pull/1065), [#1080](https://github.com/hiwavebrowser/hiwave-macos/pull/1080)); `-apple-system` treated as an unknown family, as Chrome does (CB7b, [#1074](https://github.com/hiwavebrowser/hiwave-macos/pull/1074)); settings rows (SET1 to SET5: [#1090](https://github.com/hiwavebrowser/hiwave-macos/pull/1090), [#1102](https://github.com/hiwavebrowser/hiwave-macos/pull/1102)).
- **Text rendering closer to Chrome (counted under paint):** macOS glyph masks drawn as Skia draws them ([#1030](https://github.com/hiwavebrowser/hiwave-macos/pull/1030)), quarter-pixel glyph phase ([#1054](https://github.com/hiwavebrowser/hiwave-macos/pull/1054)), Apple emoji advance ([#1072](https://github.com/hiwavebrowser/hiwave-macos/pull/1072)), emoji cluster shaping (EM1, [#1076](https://github.com/hiwavebrowser/hiwave-macos/pull/1076)).

### Stress-suite enablers (engine, JavaScript, DOM and web APIs)
- **Platform features:** the stress harness for Speedometer 3.1, MotionMark 1.3.2 and JetStream 2.2 ([#1083](https://github.com/hiwavebrowser/hiwave-macos/pull/1083)); dedicated workers with structured clone ([#1105](https://github.com/hiwavebrowser/hiwave-macos/pull/1105)); same-origin iframes as nested browsing contexts, behind a flag ([#1109](https://github.com/hiwavebrowser/hiwave-macos/pull/1109)); canvas raster ([#1136](https://github.com/hiwavebrowser/hiwave-macos/pull/1136)); the SVG transform DOM ([#1171](https://github.com/hiwavebrowser/hiwave-macos/pull/1171)); the Speedometer run path ([#1100](https://github.com/hiwavebrowser/hiwave-macos/pull/1100)).
- **JavaScript correctness and speed:** many interpreter correctness fixes, including temporal dead zones, operand order, global lexical scope and catchable stack overflow. Speed-ups include array index keys ([#1107](https://github.com/hiwavebrowser/hiwave-macos/pull/1107), [#1112](https://github.com/hiwavebrowser/hiwave-macos/pull/1112)), dropping copies of locals in the bytecode compiler ([#1149](https://github.com/hiwavebrowser/hiwave-macos/pull/1149)), inline-cache fixes, and regex literals compiled once ([#1192](https://github.com/hiwavebrowser/hiwave-macos/pull/1192)). `Array.prototype.sort` no longer panics on a comparator that is not a total order (JS2, [#1060](https://github.com/hiwavebrowser/hiwave-macos/pull/1060)). The script time budget now bounds a script (JS1, [#1048](https://github.com/hiwavebrowser/hiwave-macos/pull/1048)).
- **Page clock:** `performance.now`, frame timestamps and `Event.timeStamp` share one clock, and the content-thread clock was fixed ([#1097](https://github.com/hiwavebrowser/hiwave-macos/pull/1097), [#1104](https://github.com/hiwavebrowser/hiwave-macos/pull/1104), [#1190](https://github.com/hiwavebrowser/hiwave-macos/pull/1190)). The 60 Hz frame grid and timeline work (#1191, #1200, #1207, #1183) landed after the week closed, on 2026-11-16.

### Engine and layout
- **Grid and flex:** grid track and percentage fixes (GR1 to GR7) and flex fixes (LAY1 aspect-ratio [#1043](https://github.com/hiwavebrowser/hiwave-macos/pull/1043), CB6b, FX1). Flex and grid items enclose their floats ([#1079](https://github.com/hiwavebrowser/hiwave-macos/pull/1079)).
- **CSS and images:** `@container` queries (CQ1 to CQ3: [#1070](https://github.com/hiwavebrowser/hiwave-macos/pull/1070), [#1081](https://github.com/hiwavebrowser/hiwave-macos/pull/1081), [#1140](https://github.com/hiwavebrowser/hiwave-macos/pull/1140)). Image sizing and source selection as in Chrome ([#1039](https://github.com/hiwavebrowser/hiwave-macos/pull/1039), [#1095](https://github.com/hiwavebrowser/hiwave-macos/pull/1095)). `<img>` load events (E54, [#1019](https://github.com/hiwavebrowser/hiwave-macos/pull/1019)).
- **Paint:** positioned boxes paint at their z-index ([#1151](https://github.com/hiwavebrowser/hiwave-macos/pull/1151)); `clip-path` shapes (C8b, [#1052](https://github.com/hiwavebrowser/hiwave-macos/pull/1052)); per-thread font registration so one tab cannot change another tab's text (E56, [#1056](https://github.com/hiwavebrowser/hiwave-macos/pull/1056)).
- **Memory and tabs:** navigation releases the previous document (M2, [#1005](https://github.com/hiwavebrowser/hiwave-macos/pull/1005)); closing a tab releases its view and surface (E35, [#1003](https://github.com/hiwavebrowser/hiwave-macos/pull/1003)); atomic session save (M4, [#1018](https://github.com/hiwavebrowser/hiwave-macos/pull/1018)).

### Latency and performance (25 PRs)
- **Incremental layout:** INC5 stages 1 and 2, behind a flag that is off by default ([#1063](https://github.com/hiwavebrowser/hiwave-macos/pull/1063), [#1064](https://github.com/hiwavebrowser/hiwave-macos/pull/1064)). The LAT21 layout memo also landed off by default ([#1073](https://github.com/hiwavebrowser/hiwave-macos/pull/1073)).

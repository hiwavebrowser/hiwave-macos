Further fixes cover control line height, empty blocks, SVG transformed rects and drop-down select geometry ([#1414](https://github.com/hiwavebrowser/hiwave-macos/pull/1414), [#1416](https://github.com/hiwavebrowser/hiwave-macos/pull/1416), [#1415](https://github.com/hiwavebrowser/hiwave-macos/pull/1415), [#1369](https://github.com/hiwavebrowser/hiwave-macos/pull/1369)).

### Latency and performance (33 PRs)
- **Style writes:** a short repaint path for paint-only script style writes ([#1209](https://github.com/hiwavebrowser/hiwave-macos/pull/1209), [#1226](https://github.com/hiwavebrowser/hiwave-macos/pull/1226)), native inline-style reads and writes ([#1264](https://github.com/hiwavebrowser/hiwave-macos/pull/1264)), cheaper attribute writes ([#1219](https://github.com/hiwavebrowser/hiwave-macos/pull/1219)), and a fast path for paint-only registered transitions ([#1382](https://github.com/hiwavebrowser/hiwave-macos/pull/1382); about 43 ms to about 7 ms per frame, per the release notes).
- **Parsing and decode:** batched HTML tokens ([#1312](https://github.com/hiwavebrowser/hiwave-macos/pull/1312)), CSS declaration moves ([#1314](https://github.com/hiwavebrowser/hiwave-macos/pull/1314)), and PNG and image expansion without copies ([#1313](https://github.com/hiwavebrowser/hiwave-macos/pull/1313), [#1329](https://github.com/hiwavebrowser/hiwave-macos/pull/1329)). YouTube bundle parse time fell from 5.6 s to 1.4 s ([#1376](https://github.com/hiwavebrowser/hiwave-macos/pull/1376)), and Boa parse memory was reduced ([#1398](https://github.com/hiwavebrowser/hiwave-macos/pull/1398), [#1399](https://github.com/hiwavebrowser/hiwave-macos/pull/1399)).
- **Page clock and pacing:** a 60 Hz frame grid, the document timeline and timers on the page clock ([#1191](https://github.com/hiwavebrowser/hiwave-macos/pull/1191), [#1200](https://github.com/hiwavebrowser/hiwave-macos/pull/1200), [#1207](https://github.com/hiwavebrowser/hiwave-macos/pull/1207), [#1183](https://github.com/hiwavebrowser/hiwave-macos/pull/1183), [#1216](https://github.com/hiwavebrowser/hiwave-macos/pull/1216)). One animation round per turn sits behind a flag ([#1269](https://github.com/hiwavebrowser/hiwave-macos/pull/1269), [#1270](https://github.com/hiwavebrowser/hiwave-macos/pull/1270)).
- **Tree reuse (flag off):** retained styles and a kept box tree across script writes ([#1246](https://github.com/hiwavebrowser/hiwave-macos/pull/1246), [#1247](https://github.com/hiwavebrowser/hiwave-macos/pull/1247), [#1253](https://github.com/hiwavebrowser/hiwave-macos/pull/1253), [#1259](https://github.com/hiwavebrowser/hiwave-macos/pull/1259)).

An unrelated page

Apart from a beacon and a timer that leaves for page C (so the app logs this page's relayout summary), this page has no script. It shows a little text and one CSS animation that changes only opacity, the kind most pages run: a spinner, a pulsing badge, a fading hint. Its animation frames change no layout.

Before LAT14, if the page before it in the same tab had called element.animate(), every frame of this animation ran a full relayout (build, layout and display list), because the view's animated-style layer still held the old page's entries.
